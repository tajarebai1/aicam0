# ADR-001: مالك واحد لجلسة الكاميرا (Single Camera Owner)

- **الحالة:** معتمد
- **التاريخ:** 2026-11-18

## القرار
تملك طبقة `CameraSource` (`FlutterCameraSource`) جلسة الكاميرا الحية وحدها، مع منع فتح `camera` plugin و`YOLOView` أو أي مشغل كاميرا آخر بالتوازي. يتم إيقاف البث وتحرير الموارد تلقائياً عند انتقال التطبيق للخلفية أو طي جهاز Samsung Galaxy Z Flip3، وتطبيق آلية Backpressure (معالجة أحدث إطار فقط).

## النتائج
- استقرار أعلى على أجهزة Android القابلة للطي.
- منع تعارض الموارد وتراكم الإطارات في الذاكرة.
