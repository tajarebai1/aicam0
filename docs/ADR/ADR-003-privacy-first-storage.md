# ADR-003: الخصوصية أولاً والتخزين المحلي (Privacy-First Storage)

- **الحالة:** معتمد
- **التاريخ:** 2026-11-18

## القرار
- عدم طلب صلاحية الإنترنت (`INTERNET`) أو صلاحيات التخزين العامة (`READ/WRITE_EXTERNAL_STORAGE`).
- عدم حفظ أي صور أو فيديو أو إطارات خام أو بصمات وجوه مطلقاً.
- استخدام عدادات حية داخل الذاكرة افتراضياً، وتعطيل سجل الأحداث النصية المجهولة الهوية (`logging_enabled = false`) حتى يفعّلها المستخدم صراحةً.
- حفظ ملفات `.tflite` في التخزين الخاص بالتطبيق (`app-private`) وليس داخل SQLite.
