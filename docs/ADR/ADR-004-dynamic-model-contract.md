# ADR-004: عقد النماذج الديناميكي والرجوع التلقائي (Dynamic Model Contract & Rollback)

- **الحالة:** معتمد
- **التاريخ:** 2026-11-18

## القرار
أي نموذج يُستورد عبر Android SAF يُنسخ إلى التخزين الخاص، يُحسب له SHA-256، يُفحص توافق `model.json` الاختياري مع التنسورات الفعلية، ويخضع لاختبار دخاني (`smoke inference`) قبل تفعيله. عند فشل التفعيل يتم الرجوع تلقائياً للنموذج النشط السابق دون إظهار نجاح زائف.
