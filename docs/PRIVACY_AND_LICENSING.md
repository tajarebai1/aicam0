# سياسة الخصوصية والتراخيص — SafeZone AI Mobile

## الخصوصية وحماية البيانات
1. **العمل المحلي الكامل (Offline-First):** لا يطلب التطبيق صلاحية `INTERNET` ولا يرسل أي بيانات إلى أي خادم خارجي.
2. **لا وسائط ولا هوية:** لا يتم حفظ أي صور أو مقاطع فيديو أو إطارات كاميرا أو بصمات وجوه (embeddings) ولا يدّعي التطبيق التعرف على هوية الأشخاص.
3. **السجل الاختياري:** يتم عرض الإحصائيات الحية من الذاكرة فقط. سجل الأحداث النصية المجهولة الهوية (`monitoring_sessions`, `detection_events`) **معطل افتراضياً** ولا يُنشأ إلا بموافقة صريحة من الإعدادات.
4. **التحكم والحذف:** يمكن للمستخدم تصدير الأحداث النصية المجهولة كملف CSV، وتحديد مدة الاحتفاظ، أو حذف كامل السجل بضغطة زر.

## تنبيه التراخيص (Ultralytics AGPL-3.0)
- إذا تم تدريب أو تصدير نماذج YOLO باستخدام حزمة `ultralytics`، يُرجى مراجعة رخصة **AGPL-3.0** أو الحصول على رخصة **Ultralytics Enterprise** قبل التوزيع التجاري أو المغلق المصدر.
- كود التطبيق نفسه مبني بـ Flutter/Dart و`tflite_flutter` (Apache-2.0 / BSD).
